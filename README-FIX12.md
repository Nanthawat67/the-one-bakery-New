# THE ONE Bakery — PHASE10 FIX12

แก้ระบบ Inventory ให้เชื่อมกับ Production จริง

## สิ่งที่เปลี่ยน
- เมื่อ Kitchen เปลี่ยนสถานะออเดอร์จาก `กำลังผลิต` -> `รอแพ็ก` ระบบจะตัดวัตถุดิบตามสูตร (Recipes) × จำนวนสินค้าในออเดอร์
- การตัด Stock และการเปลี่ยนสถานะออเดอร์ทำใน transaction เดียวกัน ถ้าวัตถุดิบไม่พอจะไม่เปลี่ยนสถานะและไม่ตัด Stock บางส่วน
- ป้องกันการตัด Stock ซ้ำสำหรับออเดอร์เดิมด้วยประวัติ `inventory_movements`
- เพิ่มตาราง `inventory_movements` เพื่อเก็บหลักฐานการตัด Stock: ออเดอร์, วัตถุดิบ, จำนวน, หน่วย, ผู้ทำรายการ, เวลา และหมายเหตุ
- เพิ่ม API `GET /api/inventory/movements` สำหรับดูประวัติ
- เพิ่มส่วน "ประวัติการตัด Stock" ใน Admin > วัตถุดิบ / Stock
- การตัด Stock เกิดตอน "ผลิตเสร็จ / ส่งให้ Packing" ไม่ใช่ตอนลูกค้ารับสินค้า และไม่ถูกตัดซ้ำตอน Packing

## Flow
Customer สั่ง -> Admin ยืนยัน -> Kitchen เริ่มผลิต -> Kitchen ผลิตเสร็จ/ส่ง Packing -> **ตัด Stock** -> Packing -> ลูกค้ารับสินค้า

## หมายเหตุ
- Order ที่ไม่มีการกำหนด Recipe จะเปลี่ยนสถานะได้ตามเดิม แต่จะไม่มีรายการตัด Stock เพราะระบบไม่มีข้อมูลวัตถุดิบที่ต้องใช้
- ถ้าวัตถุดิบไม่พอ ระบบตอบ 409 พร้อมรายละเอียดวัตถุดิบที่ขาด เพื่อให้ผู้ใช้แก้ Stock/การผลิตก่อนดำเนินการต่อ
